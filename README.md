# SACDCS-OEL
# Smart Autonomous Cold-Chain Delivery & Control System (SACDCS)

## Open-Ended Lab (OEL)

**Subject:** Software Quality Engineering

## Project Overview

SACDCS is a safety-critical system designed to deliver vaccines and
temperature-sensitive medicines from a central warehouse to remote
clinics using autonomous robots.

## Project Objectives

-   Identify functional and non-functional requirements.
-   Manage change requests and requirement traceability.
-   Model robot states and verify transitions.
-   Identify conservation chamber operations.
-   Define and verify railway-crossing safety constraints.

## Task List

1.  Requirement Extraction
2.  Change Requests and Traceability Matrix
3.  State Modelling and Transition Verification
4.  Conservation Chamber Operations
5.  Constraints, Formalisation and Violations
